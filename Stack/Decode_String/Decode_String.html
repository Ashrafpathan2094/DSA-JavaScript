Key Insight

Each [ pushes a fresh frame { num, str } onto the stack. When ] is hit, pop the top frame, call str.repeat(num), then append the result to the new top frame's str — or directly to resStr if the stack is now empty. This naturally handles arbitrary nesting depth without recursion.

Solution
JAVASCRIPT 
var decodeString = function (s) {
  let stack   = [];
  let currNum = "";
  let resStr  = "";

  for (let i = 0; i < s.length; i++) {
    if (!isNaN(s[i])) {
      // Digit — build multi-digit number as string
      currNum += s[i];

    } else if (s[i] === "[") {
      // Open bracket — push frame, reset currNum
      stack.push({ num: currNum, str: "" });
      currNum = "";

    } else if (s[i] === "]") {
      // Close bracket — expand and merge
      const currStr = stack[stack.length - 1].str
        .repeat(stack[stack.length - 1].num);
      stack.pop();
      if (stack.length) {
        stack[stack.length - 1].str += currStr;
      } else {
        resStr += currStr;
      }

    } else {
      // Letter — append to top frame or resStr
      if (stack.length) {
        stack[stack.length - 1].str += s[i];
      } else {
        resStr += s[i];
      }
    }
  }
  return resStr;
};
Complexity Analysis
Time Complexity
O(n · k)
n = input length, k = max repetition factor. The dominant cost is String.repeat() inside each ] operation, which copies the accumulated substring k times.
Space Complexity
O(n)
Stack depth is bounded by nesting level. Each frame holds a partial string — total memory across all frames is O(n) relative to the input size.
